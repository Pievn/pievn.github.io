Privacy policy for Postwar uploader

Postwar uploader is used only by the owner of the YouTube channel Postwar Home Front.

The app uses the YouTube Data API to upload videos, thumbnails and video details to that one channel, and to read basic information about that channel. It does not access any other Google account or any other user's data.

The access token is stored only on the owner's private server and is never shared with third parties. No personal data of other people is collected, sold or shared.

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data retention and deletion

The only stored data is the OAuth token for the owner's own channel. It is kept only as long as the app is in use. Access can be revoked at any time at myaccount.google.com/permissions or through the Google security settings page; the stored token is then deleted from the server within 7 days. Deletion can also be requested at any time by email to the channel owner.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy.
